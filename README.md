# Federated Interpretable Speech Biomarkers for Parkinson's Detection

Code for the paper **"Federated Interpretable Speech Biomarkers for Parkinson's
Detection: Evaluating Explanation Stability"**
by Najmeh Mohajeri (Frankfurt UAS / Metropolia UAS) and Ute Bauer-Wersing
(Frankfurt UAS).

Three simulated clinics jointly train a Parkinson's disease classifier on five
interpretable speech biomarkers without exchanging any raw recordings. Because
the classifier is a logistic model on standardized clinical measures, its
coefficients are themselves the explanation. The question the paper asks is
whether that explanation stays stable under federation and non-IID
heterogeneity.

**All data is synthetic and generated by the code.** There is nothing to
download, and no clinical performance claim is made.

## Install

```bash
pip install -r requirements.txt
```


## Run

```bash
python experiment.py      # runs the benchmark, prints results, caches results.npz
python make_figures.py    # writes figures
```

`make_figures.py` runs the benchmark itself if no cache exists, so running it
alone is enough to go from a clean checkout to figures.

## Method in brief

**Biomarkers.** Five standardized measures per speaker. The articulatory anchor
is the vowel space area (VSA), the area of the /a/-/i/-/u/ triangle in the
F1-F2 plane, which contracts as Parkinsonian speech centralizes vowels. Four
phonatory descriptors complete the set: jitter, shimmer, harmonics-to-noise
ratio, and the standard deviation of F0.

**Heterogeneity.** Three sites differ in vowel-space scale, recording offset,
PD prevalence (0.45 / 0.50 / 0.55) and sample size (200 / 130 / 200), emulating
language- and vocal-tract-dependent differences across clinics.

**Training.** Full-batch gradient descent, learning rate 0.30, L2 1e-3,
T = 20 federated rounds of E = 15 local epochs, 70/30 train/test split per site.
Centralized and local-only baselines train for T x E = 300 epochs under the
same optimizer so the comparison is fair.

**Statistics.** 30 seeds with 95% confidence intervals. Federated-vs-centralized
equivalence is tested with two one-sided tests (TOST, ±0.02 AUC bound);
federated-vs-local superiority with a paired t-test, since both regimes see
identical data within a seed.

## What the results do and don't show

The match between federated and centralized training is **not** a finding. The
classifier is convex, so federated averaging converges to the centralized
optimum; the equivalence test is a sanity check that the implementation behaves
as theory predicts.

What the experiment does show is that (a) federation gives a small but
consistent advantage over siloed local training under non-IID heterogeneity,
significant only when tested pairwise, and (b) the intrinsic explanation is
stable: VSA is top-ranked in 29 of 30 seeds and every coefficient sign matches
the physiology reported in the clinical literature.

The stability claim is deliberately narrow. What is robust is the **direction**
of every biomarker and the **primacy** of VSA. The finer rank order among the
four phonatory descriptors is not stable across seeds and is not interpreted.

## Scope and limitations

- Synthetic data only. No clinical claim.
- **Data-minimizing, not privacy-preserving.** Raw recordings and features never
  leave a site, but sharing coefficients and global standardization statistics
  can leak information. Differential privacy and secure aggregation are assumed,
  not implemented.
- The classifier is intentionally simple, and the federation advantage, while
  significant, is small on this benchmark.
